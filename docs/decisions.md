# Решения по пунктам, которые методичка оставляет открытыми

Методичка [MAUT.pdf] описывает шаги метода на примере выбора площадки для
аэропорта, но не задаёт ряд деталей, нужных для программы, а в трёх местах
содержит опечатки. Ниже — что решено и почему. Номера опытов — из
`experiments/` (пересчёт: `python experiments/run_all.py`).

## Ошибки в тексте методички

| Место | В методичке | Как в программе | Проверка |
|---|---|---|---|
| Правая лотерея 160/100 млн | U(130 млн) = 0,85 | U = 0,75 | Ожидаемая полезность лотереи 0,5·U(160) + 0,5·U(100) = 0,5·0,5 + 0,5·1 = 0,75. Тест `test_curve_from_methodichka` |
| Мультипликативная функция | 1 + kU = Π[1 + k·wi·wj·Ui] | 1 + kU = Π(1 + k·ki·Ui), k из 1 + k = Π(1 + k·ki) | При Ui = 1 по всем критериям должно быть U = 1, это выполняется только для второй записи. Тест `test_solve_k_satisfies_equation` |
| Вес шума | «w3 = w1, U(150 млн) = 0,6w1» | w3 = w1·U1(x*), где x* — точка безразличия | Это та же формула, что и для w2 = w1·U1(170). При U1(x*) = 0,6 веса 0,5; 0,2; 0,3. Тест `test_weights_from_methodichka` |
| Аксиома 3 | «0 < р < 1» | 0 < β < 1 | В формуле ниже используется β |

## Детали, которые не заданы

| Вопрос | Решение | Почему |
|---|---|---|
| Число точек кривой | 3, 5, 9 или 17 (уровни лотерей 50/50), по умолчанию 5 | Опыт 2: при шумных ответах ошибка кривой минимальна на 5–9 точках, 17 точек уже хуже (ответов втрое больше, ошибки копятся). 5 точек — 3 лотереи вместо 7 |
| Между точками | Линейная интерполяция | Так построен график в методичке. При точных ответах ошибка интерполяции по 5 точкам — около 0,01 по U |
| Как ЛПР называет эквивалент | Два режима: прямой ввод числа и диалог «гарантированно x или лотерея?» с делением отрезка пополам; режим «Оба» записывает обе попытки | В методичке описан диалог («выше или ниже данного значения»), прямой ввод быстрее. Сравнение — опыт 1 и вкладка «Сравнение режимов» |
| Когда остановить диалог | Интервал уже 1 % диапазона шкалы (параметр); вопросы задаются в округлённых значениях | ~6 вопросов на лотерею. Опыт 1: при точности 5 % вопросов на треть меньше, а ошибка кривой растёт лишь с 0,015 до 0,018. ЛПР видит ровно то число, с которым работает поиск |
| Значения прочих критериев в лотереях | Наилучшие | Так проверку независимости по полезности можно совместить с построением кривой, как предлагает методичка: на проверке задаётся та же лотерея при наихудших значениях |
| «Эквиваленты одинаковы» | Разница не больше допуска, по умолчанию 10 % диапазона (параметр) | Точного совпадения при живом ЛПР не бывает. Опыт 3: при допуске 5 % проверка ошибочно находит нарушение в 25–50 % случаев, при 10 % — в 2–16 %, а нарушения, сдвигающие эквивалент на 20 % диапазона и больше, находит почти всегда |
| Приближённая или полная проверка | По умолчанию приближённая, как в методичке: первая лотерея; пары с опорным критерием. Полная — флажки на первой вкладке | Методичка допускает приближённую проверку и ссылается на Кини |
| Что делать при нарушении | Программа показывает нарушение и разрешает продолжить, результат помечается как приближённый | Методичка говорит, что единого ответа нет (разбиение на группы, переформулировка задачи) — это вне рамок работы |
| Двух критериев меньше трёх | Независимость по предпочтению выполняется тривиально | Нет «прочих» критериев |
| Самый важный критерий | ЛПР выбирает опорный критерий сам. Если на угловом вопросе важнее оказался другой, вес считается по обратной формуле wоп = wj·Uj(y*) | Веса от выбора опорного не зависят; программа подсказывает сменить опорный |
| Угловые варианты равноценны | wj = wоп, точка безразличия не нужна | Из равенства U(A) = U(B) |
| Значения прочих критериев в вопросах о весах | Наихудшие | Для аддитивной модели не важно; для мультипликативной равенство wj = wоп·Uоп(x*) верно только при наихудших прочих (их множители равны 1) |
| Абсолютная шкала ki мультипликативной модели | Вопрос о вероятности p: «гарантированно — опорный лучший, прочие худшие» против лотереи «p — всё лучшее, 1 − p — всё худшее». kоп = p, kj = p·(wj / wоп) | В методичке не описано; так делает Кини [3]. При p = 0,5 в примере Σki = 1 и модель совпадает с аддитивной. Тест `test_multiplicative_exact_dm` |
| Значение альтернативы вне диапазона | Полезность берётся на границе, выводится предупреждение | Кривая за пределами диапазона не определена |
| Изменили ответ на лотерею | Лотереи, построенные на этой точке, и их проверки сбрасываются | Их исходы изменились |
| Изменили диапазон критерия | Ответы по нему, проверки и веса сбрасываются (с подтверждением) | Ответы давались для старого диапазона |
| Порядок в режиме «Оба» | Сначала прямой ввод, затем диалог; действующим становится результат диалога | Чтобы прямой ответ не опирался на только что пройденный диалог |

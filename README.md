# MAUT — многокритериальная теория полезности

Приложение реализует метод MAUT по методичке курса: задаются критерии с
наихудшими и наилучшими значениями, проводятся лотереи для построения
функций полезности, проверяются условия независимости по полезности и по
предпочтению, определяются веса критериев и считается многокритериальная
полезность альтернатив (аддитивная или мультипликативная модель).

Эквивалент определённости и точки безразличия ЛПР может вводить двумя
способами: прямым вводом числа или в диалоге «что вы выберете?» с делением
отрезка пополам. Режим «Оба» записывает оба ответа, вкладка «Сравнение
режимов» показывает разницу, число вопросов и время.

## Запуск

Нужен Python 3.10 или новее (на Windows Tkinter ставится вместе с Python).

```
pip install -r requirements.txt
python app.py
```

Можно сразу открыть проект: `python app.py examples/airport.json`.

Расчёт по сохранённому проекту без окна:

```
python run.py examples/airport.json
python run.py examples/airport.json --model multiplicative --csv result.csv
```

Тесты и опыты:

```
python -m pytest                  # на Linux без экрана: xvfb-run -a python -m pytest
python experiments/run_all.py     # таблицы и графики в experiments/results
```

## Состав

| Путь | Что там |
|---|---|
| `maut/` | метод: критерии, лотереи и функции полезности, диалог, проверки независимости, веса, k, расчёт, файлы проекта |
| `maut/simulator.py` | модельный ЛПР для тестов и опытов |
| `app.py`, `gui/` | окно на Tkinter, по вкладке на шаг метода |
| `run.py` | консольный расчёт по файлу проекта |
| `examples/` | пример «Аэропорт» из методички: только критерии и полностью пройденный |
| `experiments/` | опыты: режимы опроса, число точек, допуск проверок, чувствительность примера |
| `tests/` | автотесты ядра и сквозной тест окна |
| `docs/decisions.md` | что методичка не задаёт или задаёт с ошибкой и как это решено |
| `docs/report.pdf` | отчёт |
